# Brand

Paper and ink. The portal and dashboard share one palette and two typefaces.

| Role | Value |
|---|---|
| Ink | `#14213D` |
| Copper accent | `#B8651B` |
| Paper | cream |
| Muted text | slate |
| Serif | Charter, with Georgia as fallback |
| Sans | Avenir Next, with the system sans as fallback |

Light only. No emoji anywhere in the UI; use text labels or CSS icons. Logo
files in this directory are the `edmund` wordmark in two sizes.
