---
name: device-troubleshooting-triage
description: Conversational triage for a malfunctioning vehicle, appliance, or piece of electronics described in text (no photo needed) — narrow the cause one question at a time instead of dumping a checklist, then say whether it's DIY-fixable or needs a professional.
---

Use this when someone describes a broken or malfunctioning physical thing (vehicle, appliance, electronics/networking gear) by symptom, without necessarily providing a photo.

1. Get identifying details if missing: exact make/model/year, and which specific unit or component is affected (e.g., which camera, which cable, which appliance model). Don't diagnose a generic "dryer" when the model matters.
2. Ask when the symptom started and what changed right before it (recent install, someone unplugged/moved something, weather, a prior repair). Regressions almost always trace to the most recent change — ask about it before anything else.
3. Isolate before advising: ask ONE narrowing question at a time and use the answer to eliminate a branch (power vs. data, mechanical vs. electrical, one unit vs. all units) before proposing the next check. Don't front-load a five-item checklist — it produces one lump answer that doesn't actually isolate anything, and burns extra round-trips reconciling which item fixed what.
4. Sequence checks cheapest/easiest first: loose connections, power source, fuses/resets — before anything requiring disassembly, purchased parts, or a technician visit.
5. Track what's already been eliminated. If the user reports "nothing is visibly damaged" or "I swapped it to a different port and it still fails," that rules out a whole branch (visual/mechanical, or that specific port) — don't ask them to recheck it, move to the next branch.
6. State plainly when the symptom pattern indicates a hardware failure no amount of troubleshooting will fix (e.g., a component that fails identically on every cable/port/outlet tried) versus a configuration or setup issue that's still fixable.
7. When the fix is DIY-reachable, give the concrete steps. When it likely needs a part or a professional, say so directly and give what to tell them (symptom description, model/part number) rather than continuing to guess at more home fixes.
8. If a photo or video would resolve real ambiguity (visible damage, an indicator-light pattern, a part number), ask for it — a picture beats another round of text description for anything visual.

Gotcha: this is about the back-and-forth diagnostic conversation itself, not about reading an already-supplied photo — if a photo is provided, use it as one more piece of evidence in the same isolate-one-branch-at-a-time approach rather than switching to a separate photo-analysis flow.
